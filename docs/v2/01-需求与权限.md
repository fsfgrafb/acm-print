# 需求与权限

基线日期：2026-10-14。除“设计默认”段落外，以下为已确认需求。

## 1. 学号与登录

所有用户可见身份名称使用部署配置的 `branding.identity_label`，当前默认“学号”，不另建用户名。后续可改为“工号”等业务名称；页面标签、提示、校验错误、管理员交接及 CSV 格式说明统一引用该配置。本文继续用“学号”描述当前规则，内部字段 `student_id` 和 CSV 列名保持稳定。内部采用不可复用的主体 ID；同一学号删除后重新导入属于新主体。完整命名契约见[业务命名配置](06-业务命名配置.md)。

首次打开前端，尚未初始化的系统要求填写首任管理员学号。服务端原子创建唯一管理员，初始密码等于学号，登录后要求进入改密流程。修改后的密码至少 4 位，允许与原密码一致。管理员重置成员密码同样恢复为学号，并重新要求改密。初始密码不因长度不足自动修改；不足 4 位时，改密流程需设置符合长度要求的新密码。

初始化完成后不得再次开放初始化接口，包括管理员到期暂缓删除、被封禁或忘记密码的情况。本地工具用于强制转让管理员，不能通过重开初始化恢复。

普通成员由管理员 CSV 导入，不开放自行注册。正式导入成功即开始固定四年有效期；上传和预览不计时。重复已有学号跳过，不重置密码、不延长期限。封禁独立于到期规则。

满四年禁止登录和新提交，并删除该主体及打印记录、关联文件；活动作业按状态文档先处置。唯一管理员未交接则暂缓到期删除。正常及本地强制交接始终仅保留一个管理员。

### 设计默认

- 学号按字符串处理，允许前导零；去除首尾空白，长度 4–64，允许 ASCII 字母、数字、连字符和下划线。初始管理员填写同样规则。
- 密码长度按 Unicode 字符计数，默认最少 4、最多 128；不自动去除空白，不要求复杂度。最少长度可管理配置，初始默认 4。
- 四年按 Asia/Shanghai 日历年计算后存为 UTC 时间；2 月 29 日的目标年份无该日时取 2 月最后一日。同一天时刻到期。
- CSV 使用 UTF-8，接受 BOM，必需列 `student_id`，可选 `email`、`phone`；页面说明列名对应“学号”。提供模板和预览；重复行标明跳过，无效行显示原因，确认时仅导入有效新学号。返回新增、跳过、无效数量。
- 预览不持久创建主体；确认时重新校验当前学号是否存在，防止并发重复导入。初始密码不作为 CSV 列接受。
- 邮箱、手机号可留空，成员修改本人信息；管理员可查看和修改，成员只能查看管理员联系方式，不能浏览其他成员联系方式。
- 接任管理员必须存在、未封禁、未到期；正常转让要求当前管理员确认密码。转让和重置密码撤销受影响会话。
- 不提供自助密码找回；成员联系管理员，管理员忘记密码使用部署机器本地工具。

## 2. 页面与交互

简洁实用，以打印和队列为主；手机适配，暂不提供深色模式。普通成员三个页面，管理员增加两个页面。

旧版 `C:\code\Rust\printing-platform\web` 的前端布局仅作参考，可借鉴导航层级、内容分区和操作位置；新版使用 React/TypeScript/Tailwind CSS 重新实现。页面及交互以本节和新版任务状态、权限契约为准，不继承旧版配额卡片、审核中心、拆页风险提醒、固定品牌文案或旧版状态含义。具体参考边界见[旧版参考与重构边界](07-旧版参考与重构边界.md)。

| 页面 | 功能 |
|---|---|
| 提交打印 | 上传/复用原件、转换状态、批量拖动排序、逐文件设置、选页后预览、确认提交；再次打印与补打回到此页，不直接出纸 |
| 任务队列 | 当前任务与全部尚未清理的历史，分页筛选；取消、再次打印、下载按权限开放 |
| 个人设置 | 学号只读、到期时间、邮箱/手机号、修改密码、退出；展示管理员联系方式 |
| 用户管理 | CSV 格式提示、预览与确认导入，封禁/解禁、重置密码、管理员交接 |
| 系统管理 | 可修改数值、容量使用、队列暂停/恢复、设备状态、统计与 CSV 导出 |

设计默认：初始选择全部页；选页区域直接显示全部、奇数、偶数、自定义选项，份数直接可见，方向与缩放在默认收起的高级设置中。手机支持拖动及上移/下移按钮。当前任务与历史在同一队列页面分区，不要求展示所有历史行到浏览器内存。

## 3. 打印范围

支持 PDF、PNG/JPG/JPEG/BMP、TXT、DOC/DOCX、XLS/XLSX、PPT/PPTX。标准 PDF 校验后保持不可变；Office 首次转换结果长期保存，升级转换器不重排历史文件。

A4、单面；默认纵向、实际尺寸。逐任务可选择横向/纵向、实际尺寸/适合可打印区域。自定义页码保留输入顺序并允许重复：`3,1,3` 输出三页。奇偶页基于原文页码。逐份打印，默认上限 20，可管理配置；`3,1` 两份输出 `3,1,3,1`。不同时让驱动与应用重复处理份数。

预览展示选页后的实际顺序和重复，并反映方向、缩放及可打印边界。实际尺寸可能裁切，不能暗中切换为 fit。重复页面计数，总页数为有序页码列表长度乘以份数，不等于物理出纸计数。

设计默认：自定义语法支持逗号、中文逗号、空白分隔，范围 `2-4` 展开为 `2,3,4`，按表达式顺序拼接；`3,1-2,3` 为 `3,1,2,3`。拒绝越界、空列表及反向范围；显式逆序通过逐页输入。前后端同一契约，服务端重新校验。

批量各文件独立设置并生成任务，按列表顺序调度。某个转换失败不妨碍提交其他已准备文件；页面明确列出未提交项。

## 4. 文件和权限矩阵

长期保存原件、首次标准 PDF、有序页码及份数；选页 PDF 按需缓存。每份下载默认是一份选页结果，不展开多份；打印份数作为任务参数。

| 操作 | 普通成员 | 管理员 |
|---|---|---|
| 共享队列学号、时间、总页数、状态 | 所有尚未清理记录 | 所有尚未清理记录 |
| 共享列表文件名与预览 | 均隐藏，包含本人条目 | 可见 |
| 原件/打印 PDF 下载 | 本人 | 所有成员 |
| 提交页预览和再次打印 | 本人有权访问的文件 | 可使用所有成员文件；新任务归操作管理员 |
| 取消排队任务 | 本人 | 所有任务 |
| 取消在印任务 | 本人，能力验证后开放 | 所有任务，能力验证后开放 |
| 暂停/恢复应用队列 | 无 | 有 |
| CSV 导入、封禁、重置、配置、统计导出 | 无 | 有 |
| 强制管理员交接 | 无网页入口 | 本地授权操作者工具 |

本人提交页预览为设计默认，解决再次打印必须核对页面的需要，不开放共享列表预览。文件名隐藏必须在服务端响应中删除，不能仅靠 CSS 隐藏；附件名称不能从他人公开队列泄露。

## 5. 历史与统计

正常历史只记录获得系统 JobId 的成功提交：学号、提交时间、文件名、总页数，提供原件和打印 PDF。队列状态用于显示当前及结束情况；内部错误信息不作为新增公共历史字段。

设计默认：统计按成功提交的任务汇总任务数和计划页数；取消或未完全出纸也不伪造物理计数。提供时间范围和学号筛选，CSV 仅管理员导出。已删除历史不保留隐藏累计账本；查询结果随到期/容量清理变化。
