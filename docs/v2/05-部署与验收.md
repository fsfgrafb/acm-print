# 部署与验收

## 1. 环境和部署边界

依据 2026-10-13 环境报告：Windows 10 IoT Enterprise LTSC 19044、i5-7500、约 8 GB RAM；目标 HP LaserJet Professional P1106、USB001。Python 3.14、LibreOffice、PDFium/GDI 单页链路已验证。报告依赖版本是探测证据，不自动作为正式项目锁文件。

首次部署锁定经验证的 Node、Python、PostgreSQL、前后端及渲染依赖。PostgreSQL 在当前 LTSC 的安装、服务与备份尚未验证。当前无需容器或额外服务器。

前端构建产物与 `/api` 同源；生产不依赖 Vite 开发服务。允许内网外访问，部署入口按实际地址配置 HTTPS，不默认向所有网络开放数据库。PostgreSQL 初期仅本机连接，独立应用非超级用户、独立迁移权限。

API、转换 worker、打印 worker 分进程，但同机运行。Windows 用户长期登录，打印进程使用有权访问固定 HP 队列的账号，在交互会话内运行，便于驱动继续弹窗。开机登录、自启与 session 行为要验收；不得把交互弹窗方案未经验证放进 session 0 服务。

## 2. 首次设置与本地恢复

首次前端访问显示首任管理员学号填写页；初始密码学号，登录后要求至少 4 位改密，可与原密码一致。并发初始化仅一个请求成功，完成标志持久保存，刷新/重启不能再次设置。

设计默认：生产首次设置在部署者控制的启动窗口完成，绑定本机或通过本地启动生成的一次性初始化凭证保护，再开放外部访问。凭证只用于防止公开空系统被抢先初始化，不增加第二种登录身份。填写学号仍在前端完成。

本地恢复工具形式拟为 `platform-admin transfer --student-id <学号>`，不是已存在命令。只允许部署机器受控操作者运行，复用管理员转让业务事务，撤销原管理员会话；不恢复默认管理员、不重开 setup、不提供无认证远程恢复入口。

## 3. 配置默认表

配置分两类：本地 `config/platform.toml` 保存业务命名等部署配置；数据库 `settings` 保存网页可管理的运行数值。业务命名不通过网页覆盖，不在数据库保存另一套副本。首次部署复制 [platform.example.toml](../../config/platform.example.toml) 为 `platform.toml` 后按业务修改，加载、校验及生效规则见[业务命名配置](06-业务命名配置.md)。新版文件不兼容旧项目 `config.toml`；新版示例还定义了服务来源、存储路径、打印设备和转换器，数据库凭据与初始化凭证通过环境变量传入。

除明确确认的值外，下表数字为设计默认；均由管理员在系统管理页调整，并提供单位、范围验证和生效说明。

| 参数 | 默认 | 生效规则 |
|---|---|---|
| 份数上限 | 20（已确认） | 新提交；不修改排队任务 |
| 总空间上限 | 512 GB（已确认） | 后台清理及容量准入 |
| 清理目标比例 | 90%（已确认） | 下次清理 |
| 密码最小长度 | 4（已确认） | 新改密，不使旧密码自动失效 |
| 文件大小上限 | 50 MiB | 新上传 |
| 批量文件数量 | 10 | 新批次 |
| 原文页数上限 | 500 | 新文件准备 |
| 单任务展开页数上限 | 1000，不含份数 | 新渲染计划/提交 |
| 图片像素上限 | 4000 万像素 | 新图片 |
| 单学号临时文件预算 | 200 MiB | 新上传；不是每日配额 |
| 转换并发 | 1 | 新认领任务，先验证资源预算 |
| 转换超时 | 120 秒 | 新转换；首启可能较慢 |
| 打印调用超时 | 120 秒 | 超时进入对账，不自动重发 |
| 状态轮询间隔 | 5 秒 | 下一轮轮询 |
| 预览 DPI / 打印栅格 DPI | 150 / 300 | 新产物版本；实际尺寸用物理单位算，不依赖像素相等 |
| 临时文件/闲置缓存保留期 | 24 小时 | 后台清理，有活动引用保护 |
| 内部诊断/幂等墓碑保留期 | 30 天 | 后台清理，见状态与数据文档 |
| session 有效期 | 30 天 | 新会话；到期/封禁立即撤销 |

固定规则不随数值配置泛化：学号四年期限、唯一管理员、A4 单面、单打印提交者。打印与转换适配能力、数据库凭据等属于部署配置，不开放任意程序路径给网页管理员执行。

设计默认：备份周期及保留期由系统管理配置，执行凭据和路径由本地部署配置。存储设置修改提示可能触发自动历史删除；保护活动任务，不在保存请求中同步执行大量清理。

## 4. 实施阶段

1. 部署命名配置加载、公开命名接口与前端文案，学号、首次管理员、CSV 预览、session、权限、PostgreSQL schema 与文件目录。
2. 原件上传/去重、标准 PDF、异步准备、选页/版面预览、缓存与下载。
3. 批次幂等、任务持久队列、Windows 适配、对账与取消。
4. 共享历史、统计导出、管理配置、容量清理、到期和本地交接。
5. 完整浏览器、故障恢复、跨设备与备份恢复验收。

每阶段围绕已确认范围实施；用户已授权开始构建项目，当前实现和待办见[实现进度](../implementation.md)。

## 5. 验收矩阵

| 场景 | 必须满足 |
|---|---|
| 业务命名替换 | 只修改配置中的平台、组织和身份显示名称，重启 API 并刷新页面后，首次设置、登录、页面标题、导航、个人设置、管理页、校验提示和导出文件名均一致；无需重新构建前端；CSV/API 字段和权限不变 |
| 命名配置校验与隔离 | 缺失、空值、未知键、非法类型及超长值启动失败并指出配置项；公开接口仅返回命名白名单，登录前可访问；HTML 特殊字符按文本显示；不会泄露凭据或内部路径 |
| 首次设置并发/重启 | 只有一个管理员；完成后永不重新开放 setup |
| 默认/重置密码 | 等于学号，强制改密；4 位边界、相同密码允许；退出/封禁/到期会话失效 |
| CSV | BOM、前导零、重复/已有、无效行和预览确认；预览无创建，重复无改密或续期 |
| 权限 | 普通共享列表无文件名/预览字段，跨主体文件访问被拒；本人下载与管理员权限正确 |
| 文件格式 | 每种已支持格式用中文/表格/图片/分页样本转换和浏览器验收；损坏、加密、不支持文件失败明确 |
| 选页 | 3,1,3 和范围混合保留顺序重复；预览与打印一致；奇偶、越界、空列表正确 |
| 版面/份数 | 横纵向、实际尺寸/fit；尺量及裁切边界；两份逐份顺序；不重复应用 copies |
| 幂等/顺序 | 双击、超时重试、多 API 进程不创建重复任务；批内按列表，不按转换完成时间 |
| 崩溃恢复 | 调用前、StartDoc 后保存前、EndDoc 错误、重启后对账；unknown 不重发且不阻塞正常设备后续任务 |
| 缺纸/继续 | 保留原 JobId，现场继续后恢复；不能解除管理员手动暂停 |
| 取消 | queued 与认领竞争；暂停作业、已进纸、多页取消，失败不伪报成功；不保证撤回已出纸 |
| 设备遥测 | USB 拔出、关机、卡纸、碳粉信号；不可用显示未知，不把驱动声明当硬件实测 |
| 到期/交接 | 四年边界、闰日、唯一管理员延期、本地恢复、活动文件保护及新同学号隔离 |
| 容量/去重 | 清闲置缓存后清历史；共享引用最后释放；活动保护；磁盘不足拒绝新上传；数据库物理空间不伪报回收 |
| 首次标准 PDF | 转换器升级后旧历史不重新分页；选页缓存删除后可按旧版本重建 |
| 部署/恢复 | 手机与另一设备上传预览打印，登录桌面自启、数据库重启、恢复备份后到期和未知对账 |

报告仅包含单页实际出纸确认；其余矩阵不是已通过测试。硬件故障验收需现场安排，不自动制造损坏或额外出纸。

## 6. 实施前不阻塞、部署前必须落实的事项

正式依赖版本、数据/备份路径、公网域名与 TLS、运行账号及自启方式在部署时确定。初始页面配色和组件库按简洁、手机可用落实，不改变业务规则。耗材遥测和在印取消不足时，保留未知提示/能力关闭，不阻塞其他已验证功能上线。
