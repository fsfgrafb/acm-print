# 架构与接口

## 1. 运行结构

React/TypeScript/Tailwind CSS → 同源 FastAPI → PostgreSQL 与受控文件目录。独立转换/派生进程处理文档，单个打印进程调用平台适配器；维护任务处理容量和生命周期。初期所有进程运行同一 Windows 主机，不引入 Redis、消息代理或容器作为必要依赖。

PostgreSQL 提供持久化任务、事务、唯一约束和协调；文件二进制存于受控目录。API 不在异步请求中直接转换或长时间调用驱动。浏览器等待任务状态而非长连接等待一次转换结束。

## 2. 模块边界

| 模块 | 职责 |
|---|---|
| 身份与权限 | 初始化、登录、学号导入、期限、管理员单例、对象授权 |
| 文件服务 | 上传校验、哈希、引用、标准 PDF 版本、授权下载 |
| 文档处理 | LibreOffice、图片/TXT 标准化、选页、页面渲染、缓存 |
| 打印业务 | 批次、有序参数、幂等、任务状态、取消、补打关系 |
| 打印适配 | 提交、作业查询、设备状态、取消、设备几何和能力 |
| 维护服务 | 容量测量、引用清理、学号到期、孤儿文件修复 |
| 配置与统计 | 本地部署配置加载与校验、公开业务命名快照、管理配置版本、成功提交历史和 CSV |

业务层不导入 Win32，也不以 Windows JobId 作为业务主键。打印适配返回通用作业引用 `{backend, queue, job_id, document_marker}`、原始状态和归一化状态；job_id 用文本保存以兼容将来的 CUPS。

Windows 第一版固定 `HP LaserJet Professional P1106`，采用 PDFium → RGB → Pillow DIB → GDI，原生 StartDocW 获取 JobId。逐页释放缓冲。Debian 将来实现同一接口；是否采用 CUPS 及实际能力另验收。平台差异不进入权限、幂等与历史业务规则。

打印器接口：`capabilities`、`device_status`、`submit`、`query_job`、`cancel_job`。能力报告包含可打印区域、方向、取消支持及耗材信息可用性；未知不等于正常。打印进程先进行作业对账，再消费新任务。

## 3. 并发和进程失效

转换按配置限并发，独立 LibreOffice profile；PDFium 在进程内串行调用。每台打印机仅一个提交者。PostgreSQL 会话级 advisory lock 作为独占协调；失去协调连接时停止新提交。作业持久记录与对账负责处理已启动的外部动作，锁本身不保证跨数据库与驱动的 exactly-once。

文件落盘采用临时路径、完整校验、原子归位再标记 ready；数据库失败留下的孤儿由维护流程扫描。上传、PDF、图片、转换都限制体积/页数/像素/超时，不按扩展名独自判定安全。宏和外部资源不作为功能执行；转换进程使用受限运行环境。

## 4. API 契约草案

所有路径以 `/api` 为前缀，公开业务命名、初始化状态和登录之外须认证；初始化接口仅未初始化时生效。以下是接口职责，不是已实现承诺。

| 接口 | 用途 |
|---|---|
| GET /public/branding | 登录前可读的业务命名白名单；仅返回平台、组织、身份显示名称及两个本地品牌资源路径，详见命名配置契约 |
| GET /setup/status；POST /setup | 查询是否首次设置；填写首任管理员学号并原子初始化 |
| POST /auth/login、logout；GET /auth/me | 登录、退出、当前学号及权限 |
| POST /auth/change-password | 改密/首次确认，允许相同密码 |
| PATCH /profile | 本人 邮箱、手机号 |
| POST /files/lookup | 仅在本人授权范围查原件哈希，命中返回引用，不泄露他人存在性 |
| POST /files；GET /files/{id} | 上传并异步标准化；查询 ready/processing/failed |
| POST /render-plans；GET /render-plans/{id} | 基于标准 PDF、页码和版面参数生成版本化预览计划 |
| GET /render-plans/{id}/pdf、pages/{n} | 受控 PDF Range 下载及页面图片 |
| POST /print-batches | 幂等提交 ready 文件、顺序、份数及预览版本 |
| GET /queue | 当前任务与成功提交历史分页；按角色输出不同字段 |
| POST /tasks/{id}/cancel | 按权限和实际状态尝试取消 |
| GET /tasks/{id}/resubmit-plan | 返回再次打印/补打的提交页初始化数据，不触发打印 |
| GET /tasks/{id}/original、pdf | 授权原件及选页打印 PDF 下载 |
| POST /admin/import/preview、commit | CSV 预览和确认，commit 重新校验并幂等 |
| PATCH /admin/students/{id}；POST /admin/students/{id}/reset-password | 封禁/资料修改；重置密码 |
| POST /admin/transfer | 正常管理员交接 |
| POST /admin/queue/pause、resume | 仅修改管理员暂停标志 |
| GET/PATCH /admin/settings | 配置快照和校验更新 |
| GET /admin/stats、stats.csv | 统计及导出 |
| GET /health/live、ready | 进程存活；数据库和关键依赖准备度 |

设计默认：状态更新先使用分页轮询，后续可增加 SSE，事件只提示重新查询，不绕过字段授权。请求错误返回稳定 code、message、request_id；不把文件路径或驱动原始异常直接暴露给普通成员。

认证采用 PostgreSQL 持久 session、HttpOnly/SameSite Cookie，HTTPS 下 Secure；状态修改校验同源/CSRF。Argon2id 保存密码。登录节流为资源保护，与已移除的打印配额无关。下载不可由公开静态上传目录提供。
