## 业务命名与复用

平台名称、组织名称和身份显示名称由新版部署配置 `config/platform.toml` 指定，不在前端、后端或打印适配器中硬编码业务名称。现有业务的命名示例集中于示例配置；正式文档使用通用平台标题。默认身份显示名称仍为“学号”，本文的“学号”指现有业务的身份标识，界面实现须读取配置。

改名只影响展示，不改变 API/CSV 字段、数据库键、权限、四年有效期和打印规则。后续业务若需要不同规则，应单独修订设计，不能通过改名隐式切换业务逻辑。统一配置加载器与公开命名接口已实现。

## 已确定技术与边界

React + TypeScript、Tailwind CSS、Python FastAPI、PostgreSQL；具体依赖版本在实施时针对目标机器验证并锁定。第一版一台 Windows 主机、一台固定 HP LaserJet Professional P1106；为未来 Debian 留平台适配接口，不预先实现多打印机产品功能。

目前不需要继续扩大需求访谈。公网入口、TLS 证书和实际部署路径可在部署阶段配置；打印故障、在印取消和精确尺寸需实机验收。若验收发现能力不足，修改能力开关与适配层，不能静默改变业务规则。
